# Figma Code Connect

## Purpose

This project uses Figma Code Connect v2 to connect Figma design-system components to their real production code implementations.

Code Connect is used only for components that have a corresponding Figma Component or Component Set.

It does not publish the website, upload project files, or require GitHub.
